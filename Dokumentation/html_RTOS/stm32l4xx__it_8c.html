◆ OS_Scheduler()

void OS_Scheduler ( void )
extern

Führt die Task-Planung (Scheduling) durch.

Implementiert ein Round-Robin-Scheduling. Es wird im Array der TCBs zyklisch nach dem nächsten Task im Zustand TaskState_Ready gesucht. Der Idle-Task (letzter Task im Array) wird dabei zunächst übersprungen. Findet sich kein Ready-Task, wird der Idle-Task in den Zustand TaskState_Running versetzt.
