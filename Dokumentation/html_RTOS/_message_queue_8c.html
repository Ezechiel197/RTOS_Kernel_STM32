Detailed Description

Implementierung einer Message Queue für die Inter-Task-Kommunikation.

Diese Datei enthält die Implementierung einer threadsicheren Message Queue basierend auf einem Ringpuffer (Circular Buffer). Sie bietet Mechanismen für Non-Blocking, Blocking und Timeout-basiertes Senden und Empfangen von Nachrichten. Die Synchronisation erfolgt über globale Interrupt-Sperren und das Auslösen eines

PendSV-Interrupts für den Context Switch.

Liest eine Nachricht aus der Queue mit Timeout.

Versucht zu lesen. Ist die Queue leer, blockiert der Task maximal für die angegebene Zeit. Erfolgt in dieser Zeit kein Schreibvorgang, kehrt die Funktion mit einem Timeout-Fehler zurück.
